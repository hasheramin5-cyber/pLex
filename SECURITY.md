# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

PulseLex is an experimental educational and research prototype. It is explicitly not designed for cryptographic privacy, authentication, or tamper-resistance. Pulse streams can be inspected and altered over clear channels.

If you discover a vulnerability or denial-of-service vector (such as an unconstrained resource consumption defect in bitstream synchronization or audio buffer synthesis):

1. Please report the issue privately by emailing the maintainer at `hasheramin.5@gmail.com`.
2. Include a minimal reproducible example, the affected module, and expected versus observed behavior.
3. The maintainer will acknowledge receipt within 48 hours and coordinate a public fix.
